## 验证脚本

### 1. 基本验证 (run_validate.py)
基本的数据格式检验，包括6项检查：
- ✅ Check 1: 必填字段 (12列都存在)
- ✅ Check 2: 数值范围 (score在[0,1]，rank≥1)
- ✅ Check 3: 信号枚举 (只包含buy/sell/hold)
- ✅ Check 4: 样本外数据 (有足够的OOS样本)
- ⏭️ Check 5: 无未来函数 (跳过，checkpoint格式不兼容)
- ✅ Check 6: Checkpoint存在 (3个模型文件都存在)

## 运行方式

### 单独运行各项验证

```bash
# 只运行基本验证
python run_validate.py

# 只计算指标
python run_metrics.py

# 完整验证 (推荐)
python run_full_validate.py
```

### 作为Pipeline的一部分

```bash
bash run_pipeline.sh
```

这会自动执行：
1. 特征工程
2. 模型训练
3. 因子推理
4. 完整验证 (包括所有指标)

## 关键指标解释

### 相关系数
- **因子值与Rank相关系数 (0.918)**: 因子值与排名高度相关，说明因子质量好
- **因子值与Score相关系数 (0.920)**: 因子值与归一化分数相关性很强
- **因子值与Signal相关系数 (0.759)**: 信号生成与因子值相关但有一定独立性

### 信号分布
- **Buy (12.5%)**: 接近设定的前10%目标
- **Sell (8.0%)**: 接近设定的后10%目标
- **Hold (79.5%)**: 中间部分，合理

### 因子值分布
- **标准差 (0.144)**: 表现出适度的波动性
- **Rank相关性 (0.918)**: 极强相关，因子排序有效

## 反馈与改进

如果验证中出现问题：

1. **缺失值问题**: 检查特征工程是否完成
2. **Rank值不对**: 检查rank计算逻辑（应从1开始）
3. **信号分布不均**: 可能需要调整buy_q和sell_q参数
4. **数据完整性**: 确保没有NaN值
